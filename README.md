# 冷凍庫の化石化防止！賞味期限パズル＆救出優先度チェッカー

冷凍庫の奥で霜にまみれた食材の詰め込み状態を入力するだけで、古い順・傷みやすい順に効率よく消費する救出メニューの順番を組み立てるツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/freezer-expiration-stock-sorter/）。
2. 画面の指示に従って操作します。
